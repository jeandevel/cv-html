# CV en HTML

CV de ejemplo hecho con **HTML y CSS** para practicar los fundamentos del desarrollo web.

> ⚠️ Todos los datos de este CV son **ficticios**. El proyecto existe solo para practicar.

## 📋 Qué incluye

- Estructura semántica con `header`, `main`, `section`, `article` y `footer`.
- Secciones de perfil, habilidades, proyectos, formación y enlaces.
- Hoja de estilos (`style.css`) en construcción.

## 📂 Archivos

| Archivo | Para qué sirve |
|---|---|
| `index.html` | Contenido y estructura de la página |
| `style.css` | Diseño y estilos |

## 🚀 Cómo abrirlo

1. Descarga o clona el repositorio.
2. Abre `index.html` en tu navegador, o usa la extensión **Live Server** de VS Code.

## 🎯 Lo que estoy aprendiendo con este proyecto

- Escribir HTML ordenado y con las etiquetas correctas.
- Conectar un archivo CSS y aplicarle estilos a la página.
- Usar Git y GitHub: commits pequeños y un historial que muestre el progreso.
